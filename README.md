# BPMグリッド倍化プラグイン
BPMグリッドのBPM値を倍々に変化させることができる AviUtl / AviUtl2 プラグインです。

また、おまけ機能としてBPMグリッドの位置調整やBPMの測定もできます。

## ダウンロード
https://github.com/Garech-mas/DoubleBPMGrid/releases/latest

上記のリンクにアクセスした後、`DoubleBPMGrid-v2.xx.zip` からダウンロードできます。

## 導入方法 (AviUtl 無印)
ZIPの中に入っている `DoubleBPMGrid.auf` を、AviUtlと同階層、または `Plugins` フォルダにコピーしてください。
- 拡張編集 version 0.92 以外のバージョンでは動作しません。

- Visual C++ 再頒布可能パッケージ 2015-2022 (x86) をインストールしている必要があります。

  https://aka.ms/vs/17/release/vc_redist.x86.exe

## 導入方法 (AviUtl2)
ZIPの中に入っている `DoubleBPMGrid.aux2` を、AviUtl2のプレビュー画面にドラッグ＆ドロップしてください。

> [!NOTE]
> For non-Japanese users, please drag and drop `DoubleBPMGrid.aux2` and `English.DoubleBPMGrid.aul2` onto the AviUtl2 preview window.

- 必ず最新バージョンのAviUtl2を導入してください。

  **対応バージョン未満の場合、プラグインが認識されない・使用できない場合があります。**

- Visual C++ 再頒布可能パッケージ v14 (x64) をインストールしている必要があります。

  https://aka.ms/vc14/vc_redist.x64.exe （DL直リンク）

## 使用方法 (AviUtl 無印)
`設定 ＞ BPMグリッド倍化の設定` から操作ウィンドウを開きます。

<img width="316" height="150" alt="image" src="https://github.com/user-attachments/assets/8ab773fd-5513-45ac-a320-4fd2b6fac8e6" />

#### BPMを半分にする / 2倍にする（グリッド間隔を広める / 狭める）
変更倍率を2に設定した場合、BPMを1/2倍・2倍に変更します。
- 変更倍率は 2~8 まで設定でき、1/N倍・N倍に変更できます。
- 倍率を変更しても拍子はそのままです。

#### BPMを元に戻す
- BPMを変更した直後の場合のみ、BPMを元に戻すことができます。
- 後述する「注意点」に該当する場合は元に戻せません。

#### BPMを測定する
- 測定したいテンポをキープしながらボタンを連続で押すと、測定結果がBPMグリッドに反映されます。
- 測定結果は整数BPMに丸められます。

#### ショートカットの設定
- `ファイル ＞ 環境設定 ＞ ショートカットの設定` から、倍率変更以外の各機能のショートカットを登録できます。

#### 注意点
- 手動でBPM設定を切り替えた場合や、シーン・プロジェクト切り替え、AviUtlの再起動を挟んだ場合はBPMを元に戻せません。
## 使用方法 (AviUtl2)
- `設定 ＞ BPMグリッド倍化` から操作ウィンドウを開きます。  
- 現在の区間のBPM、変更倍率、オフセット（秒数・フレーム数）が表示されます。
- 
<img width="272" height="277" alt="image" src="https://github.com/user-attachments/assets/1a3fd959-5e83-4d8f-bdd0-8ac521e5542d" />

#### BPMを ○倍する / ○で割る
- 「×」「÷」が含まれるボタンから操作できます。  
- カーソル位置にかかわらず、すべての区間のBPMと拍子をN倍・N分の1倍します。

#### グリッドの基準時間を戻す / 進める
- 「＜」「＞」ボタンから操作できます。  
- 現在の区間のオフセットを1フレームずつ移動します。

#### 現在フレームにグリッド基準線を追加
「＋」ボタンから操作できます。
> [!TIP]
> グリッド基準線を設定すると、以前のテンポはリセットされ、新しいBPM/拍子で刻めます。
> 後述する「BPMを測定する」と組み合わせることをおすすめします。

#### BPMを元に戻す
- BPMを変更した直後の場合のみ、BPMを元に戻すことができます。
- 後述する「注意点」に該当する場合は元に戻せません。

#### BPMを測定する
- 測定したいテンポをキープしながらボタンを連続で押すと、測定結果が記録されていきます。  
ボタンを押すのをやめた時点での測定結果が、その区間のBPMグリッドに反映されます。
- 測定結果は整数BPM・4拍子に丸められます。

#### 注意点
- 手動でBPM設定を切り替えた場合や、プロジェクト切り替え、AviUtlの再起動を挟んだ場合はBPMを元に戻せません。
